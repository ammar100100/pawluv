# Pawluv

Premium custom pet jewelry storefront.

## Current build
- Luxury Pawluv landing page
- Premium mobile-responsive layout
- Product cards for necklaces, bracelets, and keychains
- 1–4 pet selector
- Pet name + photo upload preview
- How It Works
- Before/after section
- Reviews and FAQ
- Responsive mobile layout

## Deployment
This is a static `index.html` and can be deployed directly to Vercel or any static host.
